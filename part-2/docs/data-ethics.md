# Data handling and ethics

This repository is **public** and deliberately contains no participant recordings, ELAN annotations or trained weights.

- Obtain the appropriate permission/consent before using or sharing classroom recordings, interviews, personal media or archived language-documentation material.
- Check terms of the original corpus and of every model/dataset. A recording's availability is not equivalent to permission to re-upload or publish it.
- Use locally stored media for public command-line demonstrations where possible. A remote notebook or hosted model service may transfer data externally.
- Keep raw source files and original transcriptions unchanged, with permissions protected. Derived clips and machine-generated outputs can also be sensitive.
- Do not place passwords, API keys, personal identities or unreleased transcript text in issues, commits, logs or prompts.
- Use synthetic data for unit tests and teaching examples.
- Before releasing a model, document data provenance, intended uses, known errors and limits in a model card.

The instructor's five Mandarin-class recordings are intentionally not included. If they are ever added, obtain appropriate authorisation first and document redistribution terms.
