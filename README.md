# ASR work

This repository has two teaching parts:

1. [Part 1: Whisper transcription and comparison](part-1/README.md) — a Mandarin-class CPU demonstration followed by a worked three-language comparison.
2. [Part 2: MMS ASR in Google Colab](part-2/README.md) — a browser-based notebook for inference, optional adapter training and evaluation.

[Three-language Whisper `small` audio and transcript comparison](task.md) — English, German and Maltese clips, reference text, character error rates and worked discussion points.

The classroom recordings and their precomputed transcripts are not included. Add only files you have permission to use, and follow the local data instructions in each part.
